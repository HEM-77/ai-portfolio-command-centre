# Fixture Claims Triage Assistant

TEST FIXTURE ONLY. Not project data. Used by RAG unit tests and ingestion checks.

## Objective

Route incoming insurance claims to the right adjuster queue automatically.

## Risks

Adjuster training is scheduled after go-live, so early adoption may be low.

The claims system API integration depends on a vendor release that has slipped before.

## Status Notes

Claims system API integration delayed to the next quarter. Adjusters report the triage suggestions are hard to trust without explanations.

## Lessons Learned

Train users before rollout, not after.
